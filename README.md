# HCIA Datacom — OSPF Lab Tasks

Complete lab work for 10 HCIA Datacom-level OSPF exercises, done in
Huawei eNSP using VRP CLI. Covers single-area and multi-area OSPF,
VLSM subnetting, route summarization, OSPF cost manipulation, star
and partial-mesh topologies, loopback advertisement, and a simulated
ISP–enterprise edge with default-route injection.


## Tasks
1. Basic Enterprise LAN–WAN (Single Area OSPF)
2. Branch Network Using VLSM
3. Campus Network (Multi-Area OSPF)
4. Route Summarization (Supernetting)
5. OSPF Cost Manipulation
6. Star Topology (4 Branches)
7. OSPF with Loopback Interfaces
8. Partial Mesh WAN
9. Multi-Area OSPF + Summarization
10. ISP–Enterprise Scenario
